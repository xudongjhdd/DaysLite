# DaysLite Screenshot Checklist

Use phone screenshots first. Suggested set:

1. Home screen with several countdowns
   - Caption: All your important days
2. Add countdown screen
   - Caption: Add a date in seconds
3. Countdown status examples
   - Show: Today, days left, days ago
4. Color-coded events
   - Caption: Make each day easy to spot
5. Settings and privacy screen
   - Caption: No account. Local storage.

Avoid claims such as "Best", "#1", "Free forever", or promotional badges in screenshots.
